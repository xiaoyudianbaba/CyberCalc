# CyberCalc - 赛博朋克语音计算器 🎮🔊

> 赛博朋克风格的智能语音计算器，支持语音输入、语音播报、多种音色和霓虹灯效。

## ✨ 功能特色

### 🧮 计算功能
- 基础四则运算：加法、减法、乘法、除法
- 小数点与连续计算
- 实时算式显示
- 精度控制（最多10位小数）
- 完善的错误处理（除零等）

### 🎤 语音输入
- 点击式语音输入（点击开始/停止）
- 中文数字识别（"三加五" → "3+5"）
- 数学符号智能转换
- 实时语音识别显示
- 10秒超时自动停止

### 🔊 语音播报
- **按键语音播报**：每次按键均朗读内容
- 算式自动朗读（快速模式1.5-2倍速）
- 计算结果语音播报
- 智能数字朗读（"123" → "一百二十三"）

### 🎵 三种语音模式
| 模式 | 说明 | 适用场景 |
|------|------|----------|
| **全语音模式** | 每个按键都播报语音 | 盲操作、无障碍 |
| **智能模式** | 只播报运算符和结果 | 快速计算 |
| **静音模式** | 只有音效，无语音 | 安静环境 |

### 🎭 三种音色
- **科幻电子音** 🤖 - 未来科技感
- **萝莉音** 🎀 - 可爱风格
- **御姐音** 💃 - 成熟风格

### 🎨 赛博朋克UI
- 深黑色背景 + 霓虹灯效
- 呼吸辉光动画
- 有声按键反馈
- 声波动画指示器
- Orbitron科技感字体

### 📋 历史记录
- 所有计算自动保存
- 点击历史记录重新计算
- 清空历史功能
- SQLite本地持久化存储

## 📱 使用指南

### 基本操作
1. **数字输入**：点击数字键(0-9)输入数字
2. **运算符**：点击 +、-、×、÷ 输入运算符号
3. **计算结果**：点击 = 获取结果
4. **清除**：点击 C 清除所有
5. **退格**：点击 ⌫ 删除最后输入的字符

### 语音输入
1. 点击 🎤 按钮开始语音识别
2. 使用中文说出算式（如"三加五"）
3. 再次点击 🎤 按钮停止识别
4. 识别结果自动填入计算器

### 切换语音模式
1. 点击底部导航栏「设置」按钮
2. 在「语音模式」区域选择想要的模式
3. 选择后立即生效

### 切换音色
1. 在「设置」页面找到「音色选择」
2. 点击想要的音色
3. 系统会即时应用新音色

## 🔧 常见问题

**Q: 语音识别没有反应？**
A: 请确保已授予麦克风权限，并检查网络连接。

**Q: 语音播报没有声音？**
A: 检查系统媒体音量，确保TTS引擎已安装。

**Q: 按键没有音效？**
A: 音效文件使用系统音效作为备选方案，无需额外配置。
